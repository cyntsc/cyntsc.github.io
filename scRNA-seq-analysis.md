# scRNA-seq analysis

Outline the core workflow.
- QC (mito %, nFeatures, nCounts)
- Normalization (SCTransform/log-normalize)
- Dimensionality reduction (PCA/UMAP)
- Clustering & markers
- Integration across samples
- Differential expression & enrichment
